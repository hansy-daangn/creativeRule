================================================================
당근 소재명 네이밍 스튜디오 — 요소(슬롯) · 이름 정리
================================================================

■ 파일명 패턴 (기본 슬롯 순서)
  구분_서비스_타겟_소재명_변형_매체_날짜_유형_해상도.확장자
  예시: all_maugrowth_fleamarket_bicyclea_img_2602_1080x1920.mp4

■ 공통 규칙
  - 구분자는 _ 하나, 전부 소문자, 확장자는 원본 유지
  - 선택 슬롯(구분, 변형)은 값이 있을 때만 포함
  - 빈 코드(매체 master, 구분 없음)는 해당 칸 자동 생략
  - 표기 모드: FULL(전체 표기) / SHORT(축약 표기) 전환 가능
  - 제외 대상: 촬영 원본·푸티지·텍스처·연속 프레임·gif → 00_source/ 폴더로 분리

----------------------------------------------------------------
1. 구분 (key: seg) — 선택, 코드 사전 사용
----------------------------------------------------------------
  의미            FULL         SHORT
  그로스 배치     maugrowth    mau
  없음(생략)      (빈값)       (빈값)   ← 파일명에서 생략

----------------------------------------------------------------
2. 서비스 (key: svc) — 필수, 코드 사전 사용
----------------------------------------------------------------
  의미            FULL         SHORT
  중고거래        fleamarket   fle
  알바            jobs         job
  모임            group        grp
  부동산          realty       rty
  중고차          car          car
  비즈니스        biz          biz
  브랜딩          branding     brd
  기타(fallback)  etc          etc

----------------------------------------------------------------
3. 타겟 (key: aud) — 필수, 코드 사전 사용
----------------------------------------------------------------
  의미            FULL         SHORT
  유저향          user         u
  사장님향        boss         b
  공통(fallback)  all          a

----------------------------------------------------------------
4. 소재명 (key: theme) — 필수, 자유 입력
----------------------------------------------------------------
  - 캠페인·소재 핵심을 camelCase로 작성
  - 예: demandGen, tacoNotTaco (한글은 간결한 명사)

----------------------------------------------------------------
5. 변형 (key: var) — 선택, 자유 입력
----------------------------------------------------------------
  - 에피소드/AB 표기: ep1, a, b, c
  - 같은 소재의 변형일 때만 사용

----------------------------------------------------------------
6. 매체 (key: ch) — 필수, 코드 사전 사용
----------------------------------------------------------------
  의미              FULL         SHORT
  Meta              meta         mt
  Google            google       gg
  Moloco            moloco       ml
  Naver             naver        nv
  Kakao             kakao        kk
  Toss              toss         ts
  AppLovin          applovin     ap
  당근지면          localads     la
  온드              owned        ow
  매체무관(생략)    (빈값)       (빈값)   ← 파일명에서 생략

----------------------------------------------------------------
7. 날짜 (key: date) — 필수, 자유 입력
----------------------------------------------------------------
  - YYMM 4자리 (예: 2605)
  - 이름에 없으면 파일 생성월 사용

----------------------------------------------------------------
8. 유형 (key: typ) — 필수, 코드 사전 사용
----------------------------------------------------------------
  의미      FULL    SHORT
  영상      vid     v
  이미지    img     i

----------------------------------------------------------------
9. 해상도 (key: res) — 필수, 자유 입력
----------------------------------------------------------------
  - 가로x세로 해상도 표기 (예: 1080x1920)
  - 비율(9:16 등) 표기 금지
