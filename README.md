# creativeRule → CreativeNamer로 통합됨

네이밍 규칙 편집 기능은 [CreativeNamer](https://github.com/hansy-daangn/CreativeNamer)의 **네이밍 규칙** 탭으로 합쳐졌어요.

- 바로가기: https://hansy-daangn.github.io/CreativeNamer/#rules
- 규칙은 Supabase `naming_rules`에 저장되고 웹·윈도우·맥·Figma 플러그인이 함께 사용해요.

이 저장소는 더 이상 사용하지 않아요. GitHub 설정에서 보관(Archive)하거나 삭제해도 돼요.
